Where are you now?

01Prepare your iPhoneApps, Wi-Fi, and Developer Mode

Use an iPhone on iOS 27 or later. Plug it in and connect to Wi-Fi.

  • Install Open Minis ↗ from the App Store (version 1.16 or newer).
  • Install LocalDevVPN ↗ from the App Store.

Open Minis and allow Local Network and Notifications when iOS asks. In Minis, open Settings → Network → Local Discovery and turn it on. Open LocalDevVPN and connect the VPN.

On iPhone, go to Settings → Privacy & Security → Developer Mode, turn it on, then restart and confirm. If the toggle is absent on a fresh phone, stop: this route has not been verified for enabling it.

02Pair your iPhoneRun the setup command in Minis

In Open Minis, open terminal icon → Shell Terminal and paste this command. It downloads the published setup script and runs it.

wget -qO /tmp/toke-setup.sh https://lovie97.github.io/toke-n-install/setup.sh && sh /tmp/toke-setup.sh

When the script says it is ready, start pairing and leave the silent player open. On iPhone, open Settings → Privacy & Security → Developer Mode → Pair with siboot. Enter your passcode and pairing code locally when asked.

Enter your Apple Account details only on your own iPhone. Return to Minis after pairing and keep it open until SideInstaller finishes installing. If asked, trust the developer under Settings → General → VPN & Device Management.

03Install SideStoreContinue in SideInstaller

Open SideInstaller on your iPhone. Use the same Apple Account, confirm the team, make sure LocalDevVPN is connected, then choose SideStore → Nightly → Install SideStore.

If SideInstaller reports error 7460, run the repair command from Minis:

wget -qO /tmp/toke-repair.sh https://lovie97.github.io/toke-n-install/repair.sh && sh /tmp/toke-repair.sh

The repair opens a local page. Enter the Apple Account email you used in both apps, tap Send key to SideInstaller, and confirm the import there. Then retry Install SideStore. The signing key stays on your phone.

Do not revoke certificates or delete Toke-n as a workaround. If the key does not match, stop.

04Add Toke-n in SideStoreDownload the IPA to Files

Open SideStore on your iPhone and finish its setup. Download the unsigned Toke-n IPA below, save it to Files, then in SideStore open My Apps, tap +, and select the IPA.

05Connect your providerSet your own API details

Open Toke-n and enter your provider’s API URL, API key, and model. Use the values supplied by your provider. Send a short test message to check the connection. This guide does not ask for or collect your API key.

Toke-n does not renew itself; SideStore manages signing and renewal. For each refresh, turn on LocalDevVPN and open SideStore → My Apps → Refresh All. Refresh SideStore and Toke-n every few days, before their seven-day expiry, and check the expiry shown in SideStore. Background refresh is not guaranteed.

Before you continue

A note for current Toke-n users

If Toke-n is already installed, stop before replacing it. Export your chats and keep the original app. If its app slot or bundle ID differs from this build, installing over it could make your data unavailable.

Need a hand?

Troubleshooting

Developer Mode is missing

Stop here. The path for enabling Developer Mode when the toggle is absent on a fresh phone has not been verified. Do not continue by changing profiles or certificates.

“Pair with siboot” does not appear

Check Wi-Fi, LocalDevVPN, iPhone Settings → Privacy & Security → Local Network → Minis, and Minis → Settings → Network → Local Discovery. Keep Minis’s silent player open and playing while you switch to Developer Mode. If the attempt timed out, return to Minis and rerun the setup command.

SideInstaller shows error 7460

If siboot installed SideInstaller on this phone, run the repair command in Step 3. It reuses the signing key already held in Minis. It cannot recover a key created on a different device. Stop if no matching key exists; do not revoke certificates or profiles.

SideStore cannot install or refresh

Check that LocalDevVPN is connected, the phone is online, and the same Apple Account and team are in use. Refresh SideStore and Toke-n before the seven-day signing period expires. A free Apple Account has three active sideloaded app slots shared by SideInstaller, SideStore, and Toke-n; extensions may add app ID constraints.

I already have Toke-n installed

Do not delete or replace it yet. Export your chats and keep the original app until you have confirmed the app slot and bundle ID match.

Does this work on iPad?

iPad has not been physically tested. This guide is written for iPhone.
