What stays private

This guide has no analytics, ads, account forms, or third-party scripts. GitHub hosts the page and downloads; its normal service logging and privacy policies apply. Buttons link to Apple’s App Store, the upstream projects, and the Toke-n download.

Installation uses your Apple Account inside siboot, SideInstaller, and SideStore. Toke-n uses the API connection you enter inside the app. Never paste passwords, verification codes, API keys, pairing files, signing keys, or logs containing them into GitHub issues.

The optional signing repair

The repair downloads the helper code, checks its SHA-256, and installs Python from Minis’s configured Alpine repository if needed. The helper reads one existing siboot signing key inside Open Minis. It does not upload that key, sign in to Apple, create certificates, or revoke anything.

A short-lived page bound to 127.0.0.1 checks the account email against the local account directory and hands the key to SideInstaller using its certificate-import URL scheme. SideInstaller asks for approval and checks the key against certificates on the selected Apple team before adopting it. The operating system and the two apps handle that local URL; it contains sensitive key material. Do not copy or share it. Close the Minis sheet after import.

The helper does not save the email, key, or transfer URL to a file, and its local HTTP logging is disabled. Clearing references in Python is best effort and is not a guarantee of secure memory erasure. The helper exits after one transfer or five minutes. The app’s own signing store remains in place.

GitHub hosts only public code and documentation here. No Apple Account, provider credentials, signing certificate, provisioning profile, pairing identity, or chat archive is included.
